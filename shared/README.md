# Shared contracts

Owns versioned API specifications, combat-event schemas, fighter/content definitions and common identifiers. Add `api/`, `events/` and `content/` folders when actual definitions are authored.

Share contracts across mobile, web and backend; do not assume their languages or UI code are interchangeable. Keep authoritative behavior with its owning runtime. Document compatibility and migration rules for breaking changes.

This folder currently contains no executable shared library or finalized schema.
